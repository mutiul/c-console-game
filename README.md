# C Console Guessing Game

A small number-guessing game written in C. The computer chooses a number from
1 to 100 and gives hints until the player finds it.

## Build and run

You need a C compiler and `make`.

```sh
make
./guessing-game
```

Or build and run in one command:

```sh
make run
```

Remove the compiled program with:

```sh
make clean
```
